# Security Policy

## Important Notice

Portable-Opencode downloads and executes remote binaries (Node.js, OpenCode). We take integrity verification seriously.

## Integrity Verification

All downloaded binaries are verified using:
- SHA-256 and SHA-512 checksums
- Subresource Integrity (SRI) where supported
- Version pinning via environment variables

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT** open a public GitHub issue
2. Email [TODO: your email] with details
3. We will respond within 48 hours
